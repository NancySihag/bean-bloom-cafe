# ☕ Bean & Bloom Café

A modern responsive café website built as a full-stack web development portfolio project, featuring an AI-powered chatbot.

## ✨ Features

- Responsive café website
- Modern landing page
- Menu and café sections
- Interactive frontend
- Flask backend
- AI-powered chatbot
- Mobile-friendly design

## 🌐 Live Website

https://bean-bloom-cafe-psi.vercel.app

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Flask
- Python
- Ollama
